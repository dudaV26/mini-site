# 🎸 Mini Site em HTML: A origem do Heavy Metal

## Sobre o Projeto

Este projeto é um mini site interativo desenvolvido como parte da Atividade 3 do Bootcamp PROA Frond-End. O objetivo principal é aplicar na prática os conceitos fundamentais de HTML e CSS, utilizando estruturação semântica, formulários, hiperlinks, listas e incorporação de mídia.

O tema escolhido foi **A origem do Heavy Metal**, com foco na banda pioneira **Black Sabbath**, unindo os requisitos técnicos da atividade a uma estética imersiva inspirada no Rock n' Roll.

## Estrutura do Site

O projeto é composto por três páginas interligadas, utilizando uma folha de estilo global (`style.css`):

- ** Home (`index.html`):** Apresenta a origem do Heavy Metal, suas principais características e a "Trindade Profana" do rock britânico. Utiliza estruturação com `<header>`, `<nav>`, `<main>`, `<section>` e listas.
- ** Sobre (`sobre.html`):** Uma página dedicada ao Black Sabbath, detalhando a formação clássica e a origem do som. Contém hierarquia de títulos (`<h1>` a `<h3>`), imagens e um `<iframe>` incorporando uma apresentação ao vivo do YouTube.
- ** Contato (`contato.html`):** Um formulário de contato estruturado de forma semântica (`<form>`, `<label>`, `<input>`, `<textarea>`, `<select>`, `<button>`), permitindo que o usuário envie mensagens e escolha sua vertente favorita.

## Tecnologias e Conceitos Utilizados

- **HTML5:**
  - Tags semânticas para organização correta do código.
  - Elementos de formatação e ênfase de texto (`<strong>`, `<em>`).
  - Navegação universal entre as páginas usando a tag `<a>` dentro do `<nav>`.
- **CSS3:**
  - Tema Escuro (Dark Theme) focado na paleta preta, cinza e vermelho.
  - Importação de fontes externas via Google Fonts (Oswald e Roboto).
  - Efeitos de transição (`hover`) nos botões e links da barra de navegação.
